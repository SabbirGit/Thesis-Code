# Explainable Clinical Decision Support

**Thesis project · Comparative analysis of explainable models for Clinical Decision Support Systems**

This project examines how predictive performance and model explanations can be evaluated together in clinical decision support. The analysis uses Python notebooks and MIMIC-IV clinical data.

## Evaluation framework

| Dimension | Question |
| --- | --- |
| Predictive performance | How well does each model perform on its prediction task? |
| Explanation quality | Are explanations understandable and informative about model behavior? |
| Clinical relevance | How do the explanations relate to information that matters in a care context? |
| Practical trade-offs | How do transparency, model complexity, and usefulness interact? |

## Data access

Browse the code in GitHub or open the notebooks in Jupyter. To rerun the analysis, obtain authorized access to [MIMIC-IV through PhysioNet](https://physionet.org/content/mimiciv/) and configure your local environment and data paths to match the notebook you are using.
